# Nexus Reconstructed UI

These sprites are original Nexus clean-room replacements for visual references that are serialized in the Lambda client but whose third-party source assets are not present in this repository.

They do not reproduce or redistribute the missing Unity Asset Store packages. Their `.meta` files intentionally retain the serialized GUIDs expected by the existing scenes and prefabs so those references resolve to Nexus-owned artwork.

Scope of this repair: Overworld location-card background, Barracks, Kaline Tree, Summon, Ascension, Dungeon, Shop, Campaign, Inventory icon/background, and separator.

Marker: `nexus-clean-room-ui`.
